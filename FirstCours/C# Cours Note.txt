C# Cours Note


Le c# est un language de programmation "modern" crée en 2000 orienté objet et fortement typé developpé par Microsoft.

il fait parti intergrante du .net et developpement informatique tel que jeu video, application ou meme au web. 

c# combine la puissance des language de bas niveau ( C C++) mais il a une simplicité d'utilisation et gestion de memoir comme java.

grace a ca polyvalence et son large eventail d'application,  il est devenu l'un des language les plus utiliser dans le developpement software

c# est une alternative a java pour la platform web 

c# est plus seulement utiliser pour des application windows c'est aussi utiliser dans le web ASP.net, dev mobile : Xamarin , jeu video : Unity, Cloud : Azure, Microservices et API (language de base .NET)


c'est un language orienté objet c'est donc le polymorphism, les class, l'heritage et l'encapsulation sont au centre du language.

le C# est fortement typé : chaque variable a un type clair et ne peux pas etre change facilement.

C# utiliser un garbage collector qui gere automatiquement la memoir non utilisé ce qui simplifie la la gestion de la memoire et les fuite memoire. (comme unreal)

C# garantie la securité des types ce qui signifie que toutes les convertion entre type doivent etre explicite ou controlé par le compilateur.

une classe marqué comme internal ne peux pas etre herité ailleurs que dans la classe ou elle est.

on peut rentre une methode Internal, elle sera appeller seulement dans la clase actuelle
